# 学习播放器架构（历史重构提案）

> 非当前权威文档：本文件记录重构阶段的设计推导。当前产品意图、实现和状态请从 [审阅资料入口](./README.md) 开始阅读。

本设计取代 dual-pip-architecture.md 中以窗口后端为中心的组织方式。实现顺序：领域时间轴 → 来源与设置 → 窗口装配与生命周期 → 基础交付检查。旧插件独立保留，不跨版本同步代码。

## 目标与边界

目标是边看 B 站课程边操作其他软件，并能补读快进跳过的内容。视频、弹幕、字幕来源可以组合，分 P 严格匹配。保留现有核心控件和字幕格式支持。增强窗口和原生窗口仍可选择，但来源与学习偏好不随窗口切换改变。

## 职责与依赖

- 站点适配器：识别视频与分 P、取得字幕/弹幕、更新播放列表。通过显式生命周期连接窗口；不得选择窗口后端。
- 字幕加载器：保留文件解析和网络探测；异步轨道选择使用递增请求标记，旧请求不得覆盖新选择。
- SubtitleTimeline：纯 TypeScript、无 DOM/React/配置存储依赖。轨道规范化排序，按任意时间生成 current/history 快照；不依赖播放时触发过的事件。区间采用 start <= time < end。重叠字幕全部保留，历史只取已结束字幕；默认保留最近两段，上限五段。
- SubtitleManager：作为兼容适配层，负责加载与媒体事件，把时间轴快照交给 UI；保留 row-enter/leave 接口供旧菜单与功能使用。它不决定字号、布局或小窗模式。
- 字幕呈现：DOM 与 Canvas 消费同一快照。当前字幕最下方；历史为较淡、略小字号。完整段落优先，历史从最旧开始减少，目标区域不超过窗口高 35%；当前字幕不可为满足历史预算而截断。空档不冒充当前字幕。
- 窗口装配：工厂显式创建后端，再附加站点适配器。删除生产入口对 Object.setPrototypeOf 的依赖。后端只处理窗口和承载视频的资源。
- 生命周期：打开前注册清理；重复打开受互斥保护；失败统一释放本次资源；关闭只解除自己订阅的事件，不能清空共享总线。媒体原视频仍为时间与音频来源。

## 代码取舍

| 模块 | 决策 | 理由 |
| --- | --- | --- |
| SRT/ASS/网络字幕解析，B 站分 P 探测 | 沿用 | 独立输入输出，已有真实场景积累 |
| CID 来源描述与文件资产仓库 | 沿用并解耦模式 | 内容身份正确；来源应属于视频 |
| 进度条、音量、倍速、键盘和 DOM 播放器 UI | 沿用 | 独立功能已被使用，不为外观重写播放行为 |
| 字幕逐条事件累积作为显示真相 | 重写 | 快进遗漏和后退状态处理复杂；时间查询更直接 |
| 字幕 DOM 事件状态副本 | 重写 | 直接消费同一快照，避免 Canvas/DOM 各算一套 |
| 站点与后端动态原型链拼接 | 重写生产装配 | 类型和清理边界不可见，维护成本高 |
| Canvas 打开流程 | 重写 | 必须等待实际成功、超时可退出、资源归属明确 |
| Canvas 弹幕绘制算法 | 沿用 | 排轨与字体逻辑不应因窗口变化重做 |
| 全部站点/所有历史工具文件 | 暂不清扫 | 非生产路径不为整洁而删除；后续独立处理 |

## 用户流程

网页入口可在打开小窗前选择当前视频的字幕来源。来源设置对两种窗口都可用；显式来源失败报错，不换成别的视频。当前窗口保存来源后重新加载字幕。新视频/分 P 产生新会话身份，清空上一轨道。

历史字幕默认开启、默认两段。增强小窗底栏提供“历史”切换按钮，保持记住的段数；设置字幕页同样提供开关和 1～5 段调节，原生窗口用户从网页设置控制。关闭历史只影响呈现，不关闭当前字幕。快捷开关不兼任来源选择，不在窄屏隐藏。

设置不因浏览器能力检测偷偷切换模式。窗口能力不足时明确报错，原生流的系统进度控件不承诺拥有文件视频的所有交互；网页设置和原视频控制作为明确入口。

## 状态与失败处理

idle → opening → open → closing → idle；opening 失败进入清理后 idle。只允许一个活动会话。网络回调必须检查轨道/视频代次；保存来源不覆盖其他视频的映射。清理函数可重复执行；打开中的延迟成功必须关闭已过期窗口。

## 实现边界

本轮保留共享事件总线作为旧控件兼容边界，但监听按实例记录和解除；尚未把全部旧控件改为会话注入。历史字幕段落选择共用纯函数，DOM 与 Canvas 各自进行尺寸测量。来源映射改为逐目标存储键，兼容读取旧聚合映射；不迁移旧插件数据。沿用已有界面风格和核心播放控件，不借架构重构重做所有交互。

原生模式遇到站点替换 video 节点时关闭旧窗口并提示重新打开，避免旧合成流与新字幕错配；本轮不承诺节点替换时无缝继续播放。

## 验证与交付

以下为候选交付标准，不代表已经完成真实设备稳定性验收。

仅一次针对时间轴的短检查：向前跨两段、向后跳、字幕空档和重叠字幕；一次生产构建检查导入及打包；产物 readback 验证名称/版本/固定 ID。无新增测试套，不启动日常 Edge 做长时间测试。候选功能体验由用户验收；构建成功不等于双屏/台前调度/休眠稳定性已验证。
