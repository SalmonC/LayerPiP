# B 站学习小窗：边界与视觉设计

> 0.2.1 阶段专项记录：原则可供追溯，但其中“当前判定”和版本状态可能已经过期。当前边界和审阅清单见 [review-and-boundaries.md](./review-and-boundaries.md)。

## 已定位故障

历史开关 → updateConfig(persist) → saveConfig → onSave，保存快照包含 language，旧回调无条件 location.reload。此路径与字幕是否存在无关。修复原则：配置保存不得导航、刷新或重开窗口；语言仅保存，下次主动刷新生效。无字幕不是异常，不应触发播放器生命周期。

## 功能边界及代码判定

| 功能 | 边界 | 稳定策略 / 当前判定 |
| --- | --- | --- |
| 配置 | 全量快照含语言、重复保存、存储失败 | 去掉自动刷新；保存失败可见提示；保留本次内存设置，不中断视频 |
| 历史字幕 | 无轨道、未选择、关闭字幕、轨道加载中 | 快捷按钮不可操作并说明原因；全局偏好仍可预设；不影响当前视频 |
| 字幕时间轴 | 空、非法行、负时间、重叠、字幕空档、向前/向后跳 | 按时间查询而非已播放事件；丢弃非法输入；当前/历史严格区分；历史最多五段 |
| 字幕排版 | 极长文本、窄窗口、多段换行 | 按整段减少最旧历史，当前字幕优先；不承诺无限文本仍完整可见 |
| 字幕来源 | 非 B 站、p 缺失/越界、无权限、网络失败 | 使用现有分 P 探测与选择；显式来源失败不替换成其他视频 |
| 异步轨道 | 快速选择、关窗中下载、切 P | manager 代次拒绝旧结果；站点异步弹幕同样检查代次/活动状态 |
| 来源存储 | 不同目标并发保存、旧格式 | 逐目标写入；兼容旧映射；不迁移旧插件配置；不清空其他目标 |
| 弹幕 | 空数据、下载失败、直播、超大数据 | 空数组合法，失败提示且保留视频；沿用限轨算法；海量弹幕性能未实机证明 |
| 播放 | 元数据未就绪、duration=0/Infinity、播放拒绝 | 原生打开超时/清理；进度未知不允许非法 seek；直播无历史控件 |
| 原生窗口 | video 节点替换、重复打开、打开中关窗 | 已有互斥/取消/超时；节点替换关闭并提示重开，避免画面与字幕错配 |
| 增强窗口 | 不支持 API、元数据为零、部分打开失败 | 能力报错、尺寸回退、还原原 video；不静默切后端 |
| 关闭 | 清理函数抛错、重复 close、晚到结果 | 按所有者释放；一项失败不阻止其他清理；不清空全局订阅 |
| 快捷键 | 输入框聚焦、按钮空格操作、方向键长按 | 保留现有输入过滤；按钮事件不冒泡触发播放；不占用系统组合键 |
| 设置弹层 | CSS 加载失败、极小窗口、键盘 Tab | 保底可见、焦点循环、Esc 退出、内容可滚动 |
| 扩展弹窗 | 无活动页、非 B 站、连接失效、重复点击 | 明确站点提示、禁用重复提交、连接有超时；不刷新页面自救 |
| 休眠/双屏 | 浏览器冻结、系统窗口尺寸限制 | 不新增自动刷新修复；属于待设备验收，不以静态分析宣称稳定 |

代码审查是风险筛查，不是所有浏览器状态下稳定的证明。仅对已定位逻辑做有限检查，其余明确保留设备验收边界。

### 保留风险与未证明事项

- 共享事件总线仍是兼容边界，尚未全部改成会话私有；已修正按所有者解除监听，但不等于所有第三方回调均可恢复。
- B 站接口、登录态及其他扩展对 video 的移动可能变化；不承诺与所有扩展同时启用的兼容性。
- 同一视频在多标签页同时修改来源采用后写覆盖，尚无冲突 UI；不同视频逐键隔离。超大字幕文件、长时间运行内存和海量弹幕性能未本轮实测。
- 弹窗超时仅结束等待，不强行终止浏览器已收到的窗口请求。原生后端另有取消和延迟成功清理。
- 字幕文本无限长时，当前字幕也可能超过画面；历史预算只负责先减少历史，不自动缩到不可读字号。
- 本轮不新增休眠自动恢复或页面自动刷新。构建和短逻辑检查不覆盖浏览器系统窗口、音频和双屏行为。

### 0.2.1 实施与验证

已实现无刷新保存及错误提示、历史不可用状态、参数限制、空/非法行过滤、无效时长 seek 防护、弹幕代次防护、初始化取消/晚到窗口关闭、设置焦点循环与样式失败可见、弹窗连接超时和重复打开禁用。

直接执行保存回调的有限检查验证含 language 的历史开关保存不调用 reload；空/非法字幕和非法参数检查通过。生产构建与扩展身份回读通过。未安装或实机复现，保留用户验收。

## 视觉规范（先设计后实现）

主要定位为 Bilibili 学习视频小窗，不重做 B 站主页。保留名称“叠映 LayerPiP”及扩展 ID，重画独立的播放框与字幕标识，不使用 B 站官方电视标识。

参考 BewlyCat 的语义化字号、4px 间距、卡片圆角、胶囊选择状态；不复制其源码。参考：https://github.com/keleus/BewlyCat/blob/main/src/styles/variables.scss 。设置/弹窗默认浅色，随系统深色；播放器控件始终深色。粉色强调选择，蓝色标识辅助入口。正文字号 14–15px，说明 12px，标题 20px；系统中文字体；控件 36px 起，动画 150–200ms，仅颜色/透明度。禁用持续动效和视频上方毛玻璃。

保留播放、字幕、弹幕、快捷键四组；字幕来源和历史功能独立。未加载字幕显示原因，不把无效按钮装成可用。非 B 站弹窗给出说明；本轮不扩大或改写扩展权限、持久身份。
