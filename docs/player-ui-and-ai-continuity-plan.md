# 播放器 UI、AI 连续运行与高能进度条待办

> UI 细化方案现以 [B 站 UI 重构专项计划](./bilibili-ui-refactor-plan.md) 为准；下方 UI 为早期草案。AI 连续运行与高能进度条待办仍保留。

状态：2026-09-14，已记录需求与设计，未实现。当前交付仍为 0.2.10，交付事实见 `../progress.md`。本文是这三项后续改造的权威设计；旧文档中的手动重启要求不再作为目标行为。

## 1. UI：复刻 B 站适用的播放器界面

用户要求：功能按钮的布局、内容及点击后的面板尽量完整复刻 B 站；不加入宽屏播放等小窗不需要的按钮。以用户提供的播放器与设置面板截图为视觉基准，实施前补齐实际交互对照。不是只换配色。

- 进度条在控制栏上方，播放和时间在左，适用的功能按 B 站顺序在右。图标、字号、间距、选中颜色、悬停提示、面板定位和展开方式一起对齐。
- 设置采用 B 站紧凑的深色面板、行式选项与选中态，不再嵌套大卡片。正常使用界面不显示模型全名、执行位置、技术说明或大段运行状态。
- 字幕入口归并字幕来源、AI 字幕、导入和历史访问，保留现有必要能力。AI 使用一行开关；正常运行不附加说明，等待或异常最多显示简短状态。模型与诊断详情放设置的二级页面，按需展开。
- 扩展特有功能沿用相同视觉语言；不能把自定义字幕菜单称为 B 站原有菜单的逐项复刻。先建立按钮/面板对照表，记录每一项保留、合并或不适用的依据。
- 清晰度、截图、音量、倍速、设置、小窗相关按钮需要逐项确认真实控制能力，不能只做外观或空按钮。原生小窗必须保留原有功能体验。截图中含义不明确的图标在实际站点核实后再定。
- 宽屏、网页布局切换等不适用功能不放入小窗。浏览器管理的 Document PiP 标题栏不在网页 UI 的可复刻范围内。
- 窄窗口下短标签不折行，弹层不越界；空间不足时采用紧凑布局及统一更多入口，具体断点以对照稿确认。弹层互斥，支持 Esc、点击外部关闭与焦点归还；不能再次破坏方向键、空格及输入控件的行为。

字幕菜单结构草案（仅信息层级，视觉与尺寸后续按 B 站对照稿定）：

```text
字幕                        设置 ›
AI 字幕                     开关
简体中文                       ✓
English
───────────────────────────────
导入字幕…
关联视频…
字幕历史…
```

验收重点：320 / 480 / 800 像素宽的小窗、菜单展开和关闭、正常/加载/异常状态；短标签无挤压换行、没有说明文字占据主要视频区域、功能可达。主开关关闭时隐藏 AI 入口且不初始化模型。实际视觉与设备体验由用户验收。

## 2. AI：开启意图与任务生命周期分离

用户开启一次后，跳转等内部事件不得要求再点一次开始。现版“跳转后停止并手动重启”是待修复的体验问题，不能继续作为产品约束。

### 状态与边界

分别管理：设置中的 AI 总开关、当前播放会话的启用意图、运行状态、当前显示的字幕来源。任务停止、视频元素更换和暂时故障不能顺带清除启用意图。

同一网页播放会话内，启用意图跨跳转、分 P / SPA 换视频、小窗关闭重开保留；小窗关闭可以释放采集与推理资源，重开后自动恢复。整页卸载释放会话资源；跨整页刷新、浏览器重启或其他标签页自动启用不在本轮默认范围，避免无意启动多个模型。显式关闭 AI 或总开关立即取消任务，并阻止任何旧回调重新启用。

| 运行状态 | 进入条件 | 恢复方式 |
| --- | --- | --- |
| 关闭 | 用户未启用或显式关闭 | 用户启用 |
| 准备中 | 初始化模型、绑定音轨 | 就绪后运行 |
| 运行中 | 音频与模型可用 | 随播放位置调度 |
| 重定位 | 跳转或媒体身份变化 | 合并连续事件，自动从最新位置继续 |
| 等待 | 缓冲不足、断网、暂时失败或资源冷却 | 数据/网络/资源恢复后自动继续 |
| 挂起 | 无活动输出、暂停且已有足够缓存、其他字幕被选中 | 对应条件解除后自动恢复 |
| 需要操作 | 权限被拒、模型缺失等确实无法自行解决 | 只要求解决具体条件，随后自动继续 |

“需要操作”保留启用意图，不让用户解决权限后还要重新开启 AI。无法绕过浏览器要求的授权或用户手势，不能承诺所有故障都能无人干预恢复。

### 调度不变量

1. 控制器统一协调用户意图、媒体身份和运行状态；采集源、模型、字幕展示分别负责自身生命周期。界面不能通过“任务存在与否”推断用户是否开启 AI。
2. 每次媒体变化或跳转递增任务代次，异步结果同时核对媒体身份和代次。连续跳转只处理最终位置；取消旧下载、解码与排队推理，无法立即取消的推理结果不得写回。
3. 同一视频已生成字幕可以复用；跨 CID 不混用。跳转只重排所需时间段，不反复加载模型。模型缓存有内存与空闲时限，必要释放后仍可自动重载。
4. 字幕时间采用源音频的媒体时间，不采用推理完成时刻。倍速变化调整提前量与调度预算；暂不支持的采集模式自动等待或选择兼容本地来源，恢复条件满足后继续，不能重置开关。不能为了 AI 修改视频速度、进度、音量或暂停播放。
5. 暂停后最多补齐有界提前量，然后停止持续计算；恢复播放后继续。识别落后优先处理当前位置附近，避免旧积压无限增长。历史字幕仍保留；字幕结束后不显示过期当前字幕。
6. 网络和引擎故障采用有界重试、退避与条件变化唤醒；持续失败进入安静等待，避免高频重试、重复提示与卡顿。资源过载先降负载或冷却，启用意图保留。不得静默转用云服务。
7. 切换到其他字幕源尊重用户选择，不自动抢回显示；可以挂起无用计算，切回 AI 后自动恢复。字幕显示关闭与 AI 功能关闭在操作语义上明确区分。
8. 停止时释放监听器、定时器、音频和 Worker 资源；新旧视频元素、小窗文档之间的重新绑定由控制器处理。AI 失败不能影响基础播放与快捷键。

后续定向验证：连续十次跳转仅最后一次生效；暂停/恢复；倍速切回；断网恢复；SPA 换 CID；小窗关闭重开；故障后恢复；重试期间关闭 AI 不复活；改字幕来源不被抢回。验证状态转移和资源释放，不能只测试按钮是否可点。

## 3. 高能进度条：初步可行性与证据

结论：曲线绘制和进度交互可实现，不需要 AI 模型或重新分析音频。能否与 B 站曲线一致，取决于是否能稳定取得该视频的原始数据；本轮尚未验证成功，不能标记为可直接接入。

### 本轮只读核查（2026-09-14）

- B 站工程师的历史演讲《高能进度条：视频交互体验优化》可证明该功能有真实产品与工程背景，不能据此推断今天的数据接口或算法：[演讲材料](https://static.ucloud.cn/9e53521b2b86413180ce786add891e29.pdf)。
- 公开视频页当时引用的[官方播放器脚本](https://s1.hdslb.com/bfs/static/player/main/core.9b2f4c3c.js)包含进度模块 `pbp` / `pbpstate` 状态及持久化逻辑；本轮未定位到数据获取路径。状态名称本身不足以证明接口可用或曲线含义。
- 对旧线索 `https://bvc.bilivideo.com/pbp/data?cid=1530196453` 和 `https://api.bilibili.com/pbp/data?cid=1530196453` 的公开请求均返回 HTTP 404。这只说明该路径与样本的组合未获取成功，不能推断所有视频或现有功能都不可用。
- 项目相关 API、B 站适配与播放器目录中未找到热力图适配；现有 `/x/player/videoshot` 用于预览缩略图，不应当作热力图数据。

不要在未验证数据定义前称其为“重复观看次数”“AI 精彩度”或简单的弹幕密度。

### 拟采用的路径

优先只读复用原播放器取得的数据，或通过单独适配器请求已核实的官方数据。实施前选择实际显示曲线的视频，核对请求、字段、时间步长、身份参数、权限/CORS 和缺失条件，再比对原播放器峰值位置。不先承诺某个旧接口。

适配器向播放器提供按媒体时间归一的曲线数据，按 CID 与任务代次隔离；渲染层只负责进度条上方的低矮填充曲线、已播放着色、缩放及显隐。复用同一时间坐标，不能挡住拖动、预览和键盘定位；只在数据或尺寸变化时重算轮廓，播放进度使用裁切更新。

无数据、无权限、网络异常或不支持的媒体只隐藏曲线，原进度条照常工作。拒绝 NaN、负值和异常大小，处理全零与时长不匹配；长数组按显示宽度降采样，缓存和请求有界，切 P 后丢弃旧响应。关闭高能进度条不再拉取其数据。

弹幕时间分布可以另做近似曲线，但不等于 B 站原始数据；用户要求复刻，本轮不把近似计算列为默认降级方案。如果官方数据最终不可稳定取得，记录限制，再讨论是否接受另名功能。
